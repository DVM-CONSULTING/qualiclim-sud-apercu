# Qualiclim Sud — aperçu de travail

Aperçu de la maquette du site Qualiclim Sud (climatisation réversible, de Fréjus à Cannes), publié pour la revue.

- **Ce n'est pas le site de production.** Les éléments marqués « À CONFIRMER » attendent les informations du client ; les visuels marqués « Visuel de démonstration » et les prix « fictifs » du simulateur seront remplacés.
- La page porte `noindex, nofollow` : elle ne doit pas être référencée par les moteurs de recherche.
